# 八种房间灯光接入与进房闪动修复

主预览：http://127.0.0.1:5173/

## 范围

将已认可的方案（1）应用到学习工作、睡觉、用餐、居家、通勤、户外、社交、娱乐八类房间：墙面上亮下暗的连续明度渐变、较低的均匀环境光、顶部暖白主光及支持投影的实时聚光。各房间分别设置强度，没有将用餐房方案（2）的数值统一套给其他房间。

用餐房保留顶部面光 3.1，聚光近景 6 / 整楼 2.5；睡觉房保留面光近景 1.6 / 整楼 0.65、聚光近景 3 / 整楼 1.2。其他房间使用更克制的独立参数。主曝光、色调映射、CMF、模型名称和层级未改。

顶部面光每层复用一盏；焦点聚光复用现有可投影的 SpotLight，没有为每个房间增加多张阴影贴图。原有 pooled area 在非用餐房关闭，避免与新的顶部面光重复照明。进房过程按镜头进度渐变环境光与补光强度，整楼视角不全局压暗其他房间。墙面材质按房间独立克隆，使用动态高度 uniform，楼层高度和位置变化时不会串房或失去渐变；移除楼层时释放新增材质。

未启动任何烘焙，没有加载 study-04 / meal-ao-01 的实验结果。保留主模型原有材质与贴图；其中部分家具本来使用固定 Lightmap + MeshBasicMaterial，对实时灯光响应有限，此次不擅自替换这些已认可的家具材质。

## 已复现的闪动原因与修复

1. 退出尚未完成时再次进入：旧 camAnim.fromBlend 仍在缩小 roomBlend。原版复现数据中，已进入睡觉房，blend 却从 0.999 降至 0.716，相机 Z 从 7.7 拉到 19；之后才再次放大。修复为新进入操作清除旧退出动画，并从当前实际相机位置、朝向、FOV 接续过渡。
2. 原本在 roomBlend > 0.5 时一次性开启完整强度 GTAO，产生一次暗部跳变。改为根据进度连续渐入/渐出。
3. 阴影原本每五帧更新一次，即使镜头在切换房间。现在首次渲染立即生成阴影，进出房间的过渡期间逐帧更新，稳定后继续原有节流。
